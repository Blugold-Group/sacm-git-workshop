# Members

One file per person, named after your GitHub username: `members/<username>.md`.

Start from [`_template.md`](_template.md). Files starting with `_`, and this
README, are skipped by the automated check.

Why one file each instead of one big list? Because everyone can open a pull
request at the same time without editing the same lines, so nobody hits a
merge conflict. (Want to see a conflict anyway? Try
[the merge conflict exercise](../exercises/02-merge-conflict/).)
